# ENCORE — ვებსაიტი და ადმინ პანელი

ლითიუმის ბატარეების მეორე სიცოცხლე. Node.js + Express + EJS + SQLite (Node-ში ჩაშენებული) + Tailwind CSS.

## რა არის საიტზე

**საჯარო მხარე** (`/`): მთავარი (სტატისტიკა, როგორ მუშაობს, პროდუქტები, გარემოს დაცვა), პროდუქტები, ჩვენ შესახებ,
კონტაქტი / ბატარეის ჩაბარება, გამოწერა (შეკვეთა).
ქართული / ინგლისური, ნათელი / მუქი თემა.

**ადმინ პანელი** (`/admin`): დაშბორდი სტატისტიკით, ელემენტების (პარტიების) დამატება და რედაქტირება,
პროდუქტები (1–3 ფოტო, „-დან“ ფასი), შეკვეთები, ჩაბარების მოთხოვნები და წერილები, ადმინები (მაქს. 5; ახალს მხოლოდ
Super admin ქმნის), საიტის პარამეტრები (ტელეფონი, ელ-ფოსტა, მისამართი, სოციალური ქსელები, მთავარი გვერდის ტექსტი).

## ლოკალურად გაშვება

საჭიროა Node.js 22.13 ან უფრო ახალი.

```bash
npm install
npm start
```

გახსენი http://localhost:3000, ადმინ პანელი — http://localhost:3000/admin.
შესვლის მონაცემები (`ADMIN_USERNAME`, `ADMIN_PASSWORD`) ჩაწერილია `.env` ფაილში.
შესვლის შემდეგ პაროლი შეცვალე: **ჩემი ანგარიში** (ქვედა მარცხენა კუთხე).

დიზაინის (CSS) შეცვლის შემდეგ: `npm run build:css`.

## Railway-ზე გაშვება

1. ატვირთე `encore-site` საქაღალდე GitHub-ის რეპოზიტორიაში (`.env` და `data/` არ იტვირთება — ეს სწორია).
2. Railway → **New Project → Deploy from GitHub repo** → აირჩიე რეპოზიტორია.
3. სერვისზე **Volumes → New Volume**, Mount path: `/data` (ამის გარეშე ყოველ განახლებაზე ბაზა და ფოტოები წაიშლება).
4. **Variables**:
   | ცვლადი | მნიშვნელობა |
   |---|---|
   | `DATA_DIR` | `/data` |
   | `ADMIN_USERNAME` | მაგ. `superadmin` |
   | `ADMIN_PASSWORD` | ძლიერი პაროლი |
   | `SESSION_SECRET` | გრძელი შემთხვევითი ტექსტი |
   | `NODE_ENV` | `production` |
   | `SEED_DEMO_CELLS` | `false` — თუ სატესტო პარტიები არ გინდა |
5. **Settings → Networking → Generate Domain** — მიიღებ საჯარო ბმულს.

Railway თავად გაუშვებს `npm install`, `npm run build` (CSS) და `npm start`-ს. პორტს (`PORT`) Railway თავად აწვდის.

`ADMIN_USERNAME` / `ADMIN_PASSWORD` გამოიყენება მხოლოდ პირველ გაშვებაზე, როცა ბაზაში ადმინი ჯერ არ არის.
შემდეგ პაროლი ადმინ პანელიდან იცვლება.

## სტატისტიკის ლოგიკა

- **მიღებული** — ყველა პარტიის რაოდენობის ჯამი; **გაცოცხლებული** — A, B, C კლასი; **გადამუშავებაზე** — D კლასი.
- **kWh მეორე სიცოცხლეში** — რაოდენობა × ტევადობა (Wh) × SoH. თუ SoH არ არის შეყვანილი, კლასის საშუალო გამოიყენება (A 85%, B 75%, C 65%).
- **კგ გადარჩა ნაგავსაყრელს** — რაოდენობა × წონა (შეყვანილი, ან ფორმის მიხედვით შეფასებული: 18650 ≈ 46 გ, 21700 ≈ 68 გ).
- **CO₂** — გაცოცხლებული kWh × 100 კგ (ახალი ბატარეის წარმოების საშუალო ემისია, 60–150 კგ/kWh დიაპაზონიდან).

## საიტი GitHub Pages-ზე (QR კოდისთვის)

მომხმარებლის საიტი (ადმინ პანელის გარეშე) ავტომატურად ქვეყნდება მისამართზე
**https://gigioboladze.github.io/ENCORE/** — ყოველ `git push`-ზე GitHub Actions (`.github/workflows/pages.yml`)
თავიდან აწყობს გვერდებს (`npm run build:static`) და აქვეყნებს. ასე QR კოდი ყოველთვის უახლეს ვერსიას ხსნის.

- **საკონტაქტო ინფორმაცია** (ტელეფონი, ელ-ფოსტა, მისამართი, სოციალური ქსელები) იცვლება ფაილში `site.config.json`.
  შეცვალე GitHub-ზე პირდაპირ → Commit → 1–2 წუთში საიტი განახლდება.
- **ფორმები** (ბატარეის ჩაბარება, შეკვეთა): სანამ სერვერი (Railway) არ არის გაშვებული, ფორმა ხსნის ელ-ფოსტას შევსებული ტექსტით
  `site.config.json`-ში მითითებულ მისამართზე. Railway-ს გაშვების შემდეგ GitHub-ზე: **Settings → Secrets and variables → Actions →
  Variables → New variable** `STATIC_API_URL` = Railway-ს მისამართი (მაგ. `https://encore.up.railway.app`) — მაშინ ფორმები
  პირდაპირ ადმინ პანელში ჩავარდება.
- სტატისტიკა და პროდუქტები GitHub Pages-ზე აიწყობა საწყისი (სადემონსტრაციო) მონაცემებით.

ლოკალურად შემოწმება: `BASE_PATH=/ENCORE/ npm run build:static` → ფაილები `dist/` საქაღალდეში.
